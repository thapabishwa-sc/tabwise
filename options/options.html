On-device AI in this browser

Which built-in AI APIs your Chrome exposes, measured here rather than assumed. The model itself is not selectable — Chrome's Prompt API gives you Gemini Nano and takes no model parameter — but the task-specific APIs below are separate models, and a missing one explains a missing capability.

Refresh AI context starts the model on a clean slate and re-reads pages next time: it destroys the current model session and clears the cached page summaries and stored explanations. Learned tasks are left alone — forgetting those is the separate button below.

Reading page content

A title is usually enough to say what a page is about — but not always. An untitled document, a dashboard called "Grafana", an app that never sets its title: those tabs have no description at all, and end up grouped by little more than their address.

Granting page access lets a summary of each page be read instead: its headings, its meta description, and the first few hundred characters of the main text. Never form fields, never the whole page. It stays on this machine — the extension makes no network requests of any kind — and is cached only until the browser closes.

This is the extension's only permission that touches page data, it is off until you grant it, and revoking it puts everything back exactly as it was.

What it has learned

Every group you rename, and every tab you file by hand, teaches this list. A task here is recognized instantly next time — no AI call — and keeps the name you chose.

Each signal below is one thing the task is recognized by. Remove a bad one with its × and it will not be learned again, even if the same tabs come back — often better than forgetting the whole task. Add a word to make a task match something it keeps missing.

Pinned Rules

Force certain URLs into a fixed group, bypassing the AI. One rule per line as match = Group Label. The match can include a path for finer control.

The left side is matched as a substring of the tab's hostname + path (case-insensitive). First match wins — list more specific rules first. Advanced regex capture rules (e.g. group Jira by project key) are applied via Import and preserved here.

Report a grouping problem

Grouped something wrong? Capture the window as a test case. The gold field is pre-filled with where each tab actually landed, and _why records which stage put it there — correct the ones that are wrong, and it becomes a fixture that can be measured and fixed rather than guessed at. URLs have credential-shaped query parameters and fragments removed, but read it before sharing: titles and paths are included as-is.
