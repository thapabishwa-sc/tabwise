Grouping

Manual only groups when you click "Group all", run a command, or capture a task — tabs never move on their own. Automatic also groups each new tab as it loads.
When the AI names groups, bias toward the project or task each tab supports (work-streams) rather than its generic topic.
A tab opened from another tab joins that tab's group right away — following a link from a ticket to its pull request keeps them together. The most reliable "same work" signal there is, and it needs no AI call. Turn off to classify every new tab from scratch.
Automatically collapse a group as soon as you switch to a tab outside it; only the active group stays open.

What it has learned

Every group you rename, and every tab you file by hand, teaches this list. A task here is recognized instantly next time — no AI call — and keeps the name you chose. Forget one if it starts pulling in the wrong tabs.

Pinned Rules
